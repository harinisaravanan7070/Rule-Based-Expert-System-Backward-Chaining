# Rule-Based Expert System – Backward Chaining

## Objective

Develop a simple expert system for **Student Academic Guidance** using Backward Chaining.

## CSP Structure

* **Facts:** Attendance, assignments, exams, projects
* **Rules:** Academic guidance rules
* **Goal:** Eligible for Placement
* **Method:** Backward Chaining

## Working

The system starts with a goal and works backward to check whether the required facts are available.

## Technology

* Python
* Rule-Based Expert System
* Backward Chaining
